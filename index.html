TEKNOLOGI & PENDIDIKAN

Perjalanan Saya Belajar Pemrograman

Cerita tentang proses belajar, mencoba hal baru, dan membangun masa depan di dunia teknologi.

Ditulis oleh Nabila Maulida · 21 Oktober 2026

Menjadi mahasiswi Teknik Informatika merupakan pengalaman yang menarik bagi saya. Saya belajar bahwa perkembangan teknologi tidak hanya berkaitan dengan komputer, tetapi juga tentang bagaimana manusia dapat menciptakan solusi untuk berbagai permasalahan dalam kehidupan sehari-hari.

Pada awal belajar pemrograman, saya menyadari bahwa menulis kode membutuhkan ketelitian, kesabaran, dan latihan yang konsisten. Terkadang program yang saya buat tidak berjalan sesuai harapan. Namun, kesalahan tersebut justru menjadi kesempatan untuk memahami cara kerja program dengan lebih baik.

"Keberhasilan dalam pemrograman bukan hanya tentang seberapa cepat kita menulis kode, tetapi juga tentang seberapa baik kita memahami masalah dan menemukan solusinya."

Saya mulai tertarik mempelajari teknologi web karena hasilnya dapat langsung dilihat melalui browser. HTML membantu saya menyusun struktur halaman, CSS membuat tampilan lebih menarik, sedangkan JavaScript memungkinkan halaman menjadi lebih interaktif.

Hal yang Saya Pelajari

Dalam proses belajar, saya mencoba membangun kebiasaan untuk mempelajari konsep dasar terlebih dahulu sebelum mengerjakan proyek yang lebih kompleks. Beberapa hal yang ingin terus saya kembangkan antara lain:

  • Memahami HTML untuk membangun struktur halaman web.
  • Menggunakan CSS untuk mengatur tata letak dan tampilan.
  • Mempelajari JavaScript untuk membuat fitur interaktif.
  • Berlatih memecahkan masalah melalui proyek sederhana.
  • Mempelajari Git untuk mengelola perubahan kode.

Untuk menambah wawasan, saya juga memanfaatkan berbagai sumber belajar di internet. Saya dapat membaca dokumentasi HTML, CSS, dan JavaScript melalui MDN Web Docs. Saya juga menggunakan W3Schools sebagai referensi untuk mempelajari contoh kode, serta freeCodeCamp untuk berlatih melalui materi pemrograman.

Harapan Saya ke Depan

Saya ingin terus meningkatkan kemampuan dalam bidang pemrograman dan pengembangan perangkat lunak. Bagi saya, proses belajar tidak berhenti ketika sebuah tugas selesai. Masih banyak teknologi baru yang dapat dipelajari dan berbagai ide yang dapat diwujudkan menjadi aplikasi bermanfaat.

Saya berharap suatu hari nanti dapat menjadi programmer profesional yang mampu membangun website atau aplikasi berkualitas. Saya percaya bahwa usaha kecil yang dilakukan secara konsisten dapat membawa perubahan besar dalam perjalanan menuju cita-cita.

Ditulis dengan semangat belajar dan berbagi.
